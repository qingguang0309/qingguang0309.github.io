01 Featured work

Adapting and optimizing MiroFlow for Keen AgenticOS

I adapted the open-source MiroFlow research-agent framework for the KeenData team and optimized it around one idea: a hard question is usually lost at the final judgment, not in search.

  1. Neutral orchestration

    Sub-tasks ask for data, never for a pre-chosen reading of the question.

  2. Evidence-first workers

    Workers return verbatim quotes, sources and archived values, not conclusions.

  3. Terminal adjudication

    Every defensible candidate stays alive; they are compared once, from the question-writer's point of view.

  4. Traceable verdict

    The final answer is transcribed from the evidence, never re-solved.

Reliability
A launch gate (API preflight, smoke run, trace check) and a run guard that keep long evaluation runs safe.
Routing
Claude, GPT, Kimi and Gemini as interchangeable main models, with hardened audio, video and file-reading tools.
Output
Deterministic format checks and normalization, so a correct answer is never lost to formatting.
Integrity
Search and fetch filters that keep the agent away from leaked benchmark answers.
